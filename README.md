# OJ判题系统代码沙箱
在知识星球的OJ判题系统下的代码沙箱进行了功能扩展，提供开放 API 接口，支持作为独立服务向第三方系统开放调用。

开发方式： 采用idea远程开发

相关项目：

项目前端部分 链接： [oj代码沙箱](https://github.com/YhzDetermined/HZOJ-sandbox)

项目后端部分 链接： [oj判题系统后端](https://github.com/YhzDetermined/HZOJ-backend)

## 项目结构
``/src``目录中是代码沙箱的Java代码，``/tmpcode``目录中是未为存放用户提交代码的临时文件夹，当用户提交的代码完成判题，会删除相关文件夹

## 代码沙箱传入参数

json请求体格式，提交方式 POST。请求包含测试用例，代码，编程语言，时间限制（可选）,空间限制（可选）
```
{
  "inputList": [],    
  "code": "",
  "language": "",
  "timeLimit": "",
  "memoryLimit": ""
}
```
## 扩展主要工作
- 优化判题过程：之前每次提交都会open-jdk8镜像是否存在，现在在加载配置类时即判断是否存在该镜像，如不存在下载镜像
- 修复了提交代码后沙箱依旧在不停进行内存统计的bug
- 对编译错误和运行错误两类错误增加了处理，将报错信息增加到请求体中
## 代码沙箱工作流程
1. 将用户的代码保存为文件
2. 使用Runtime类用javac编译代码，得到class文件 
3. 运行代码。运行代码分别实现了Java原生代码沙箱和Docker隔离代码沙箱

### Java原生代码沙箱
通过**java命令**运行代码
4. 统计程序占用时间和空间
   - **程序占用时间统计**：通过新建一个StopWatch统计程序运行时间，获取执行时间在StopWatch执行前后统计时间
   - **程序占用内存统计**：需要借助第三方工具统计程序消耗时间
> 运行简单程序两数之和耗时约90ms

### Docker隔离代码沙箱 
通过Docker Java SDK（导入相关Maven依赖）操作Docker，创建DockerClient
在项目启动的时候，先判断有无openjdk镜像，如果无，下载镜像（这部分代码在static代码块中）
1. 创建容器的时候指定大小和对应openjdk镜像，将程序所在目录挂载到docker容器目录上
2. 在已有容器中执行命令
3. 通过CallBack回调获取执行结果
4. 统计程序占用时间和空间
   - **程序占用时间统计**：通过新建一个StopWatch统计程序运行时间，获取执行时间在StopWatch执行前后统计时间
   - **程序占用内存统计**：内存因为程序占用的内存实时在变化，定义一个周期定期统计Docker容器内存情况
  > 运行简单程序两数之和耗时约400ms
